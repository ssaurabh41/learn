# STA Summary Table — Theme Spec ("Gold ledger", neutral)

Purpose: one compact table that summarizes STA timing reports across scenarios, so a
reviewer can see in seconds what fails, where, and by how much. Everything else is noise.

Reference render: `sta_summary_example.html` / `sta_summary_example.png`.

## 1. Content rules

- **One line of context, no page header or footer.** Design name (bold), run tag, netlist
  version, scenario count, units. No logos, timestamps of generation, banners, or "generated by".
- **One table.** One row per scenario (`mode · corner`). Last row = **worst across scenarios**.
- Columns, grouped:
  - Scenario
  - **Setup:** WNS · TNS · NVP
  - **Hold:** WNS · TNS · NVP
  - **DRV:** Tran · Cap (add Fanout only if the flow checks it)
  - Status
- Units stated once (in the context line), never repeated in cells.
- Row order: as in the scenario list of the run. Do not sort by severity; reviewers know the
  order and look for a scenario by position.
- Worst row: WNS = min over scenarios; TNS and NVP = sum over scenarios; DRV = sum.
  State this rule in the tool's docs, not on the page.
- Status: `FAIL` if any WNS < 0 or any DRV > 0; `MARGIN` if any WNS < margin threshold
  (default 0.005 ns, configurable); else `PASS`.

## 2. Fonts

| Role | Font | Size / weight |
|---|---|---|
| Labels, headers, scenario names, status | Inter (fallback system-ui, sans-serif) | 13px; headers 600 |
| Numbers | JetBrains Mono (fallback SF Mono, Menlo, monospace) | 12.5px, 400; violations 600 |
| Design name in context line | Inter | 15px, 600 |

`font-variant-numeric: tabular-nums;` on all numbers. Line height 1.35.

## 3. Color tokens

Neutral greys carry the page; gold is used **only** for structural lines; red only for violations.

```css
:root {
  --bg: #ffffff;       --bg-head: #f4f5f6;  --bg-hover: #f9fafb;
  --ink: #1f2328;      --ink-muted: #6b7280;
  --gold: #9c7c2e;     /* structural lines only */
  --grid: #dcdfe3;     /* inner cell grid */
  --fail: #b42318;     --warn: #8a6100;     --pass: #6b7280;
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) {
    --bg: #16181b; --bg-head: #1f2226; --bg-hover: #1b1e21;
    --ink: #e6e8eb; --ink-muted: #9aa1ab;
    --gold: #b8954a; --grid: #33373d;
    --fail: #f07167; --warn: #d9a441; --pass: #9aa1ab;
  }
}
```

## 4. Borders (the signature of this theme)

- Gold lines (2px `--gold`): outer table border, column-group dividers (before Setup,
  Hold, DRV, Status), header bottom (full width, including rowspan cells), worst-row top.
- Everything else: 1px `--grid` neutral grey.
- Keep gold at 2px. At 1px it ties with the grey grid in `border-collapse` and disappears.
- No rounded corners, no shadows, no fills except `--bg-head` on header and worst row.

## 5. Cells

- Padding 5px 10px. `white-space: nowrap`.
- Header background `--bg-head`, centered text, two header rows (group, then metric).
- Scenario column left-aligned: mode in `--ink`, ` · corner` in `--ink-muted`.
- Numbers right-aligned, 3 decimals for slack (ns), integers for counts.
- **Violation** (negative slack, NVP > 0, DRV > 0): `--fail`, weight 600.
- **Zero counts / zero TNS**: `0` in `--ink-muted`, so non-zero values stand out.
- Positive slack: plain `--ink`.
- Status cell: centered uppercase word, text color only (no cell fill).
  FAIL = `--fail` 600; MARGIN = `--warn` 600; PASS = `--pass` (grey) 500.
  PASS is deliberately quiet; the eye should land on what needs action.
- Worst row: weight 600, background `--bg-head`.
- Row hover: `--bg-hover`.

## 6. Layout

- Max width 1040px, 16px side gutter, 20px top/bottom.
- 10px gap between context line and table.
- Wrap the table in `overflow-x: auto`; only the table scrolls on narrow screens.

## 7. Don'ts

- No title block, footer, legend, logo, or generation timestamp.
- No zebra striping, gradients, icons, or emoji.
- No color on positive values or PASS; no colored cell fills; no green.

## 8. Checklist

- [ ] Every negative slack and non-zero count is red and bold; nothing else is.
- [ ] Worst row matches the min/sum rule.
- [ ] Digits align vertically.
- [ ] Readable in light and dark mode; status readable without color.
